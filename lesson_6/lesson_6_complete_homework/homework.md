## Домашнее задание: Уведомления о новых постах с использованием Pub/Sub и SSE

### Цель
Реализовать в приложении механизм уведомлений, при котором, когда автор публикует новый пост, его подписчики (или любой заинтересованный клиент) получают уведомление в реальном времени через систему Pub/Sub Redis и Server-Sent Events (SSE).

### Задачи

1. Публикация уведомлений при создании поста:
   - В эндпоинте создания поста (например, `POST /posts/create/`) после сохранения нового поста в базе данных добавить логику публикации уведомления.
   - Уведомление должно публиковаться в Redis-канал с именем, привязанным к ID автора, например: `new_post:{author_id}`.
   - Сообщение должно содержать данные нового поста (ID, заголовок, краткое описание и т.д.), сериализованные в формат JSON.

2. Реализация подписки на уведомления через SSE:
   - Создайте новый эндпоинт (например, `GET /notifications/subscribe/{author_id}`), который позволяет клиенту подписаться на уведомления от конкретного автора.
   - Используйте Server-Sent Events (SSE) для отправки сообщений клиенту в режиме реального времени.
   - Эндпоинт должен использовать Redis Pub/Sub для подписки на канал `new_post:{author_id}` и отправлять полученные уведомления клиенту.

3. Документация:
   - Документируйте все новые эндпоинты в Swagger UI.

### Важные аспекты

- Публикация уведомлений:  
  При создании нового поста уведомление должно публиковаться в соответствующий Redis-канал (например, `new_post:1` для автора с ID 1).

- Подписка через SSE:  
  Клиент, подписавшийся на эндпоинт `/notifications/subscribe/{author_id}`, должен получать уведомления в режиме реального времени, как только в канал поступят сообщения.

- Документация и комментарии:  
  Код должен быть хорошо прокомментирован, а эндпоинты задокументированы в Swagger UI.

### Итог

После выполнения задания ваше приложение должно позволять:
- Аутентифицированным пользователям создавать посты, при этом автоматически публикуя уведомления.
- Клиентам подписываться на уведомления по определённому каналу и получать их в реальном времени.
- Демонстрировать практическое применение Redis Pub/Sub и SSE для построения динамичных уведомлений.
