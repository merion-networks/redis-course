# Финальный практический проект: Онлайн-чат на FastAPI и Redis

## Цель проекта

Разработать онлайн-чат с авторизацией, передачей сообщений в реальном времени и использованием Redis как основной инфраструктурной технологии.

Проект должен демонстрировать знания и навыки, полученные в ходе курса, включая работу с WebSocket, Redis Pub/Sub, Redis Streams и базовую авторизацию.

---

## Функциональные требования

### 1. Авторизация и регистрация

- Возможность зарегистрировать нового пользователя (с логином и паролем).
- Возможность авторизоваться и получить сессионный токен.
- Сохранение токенов в Redis (`token:{uuid}` → username).
- Выход из системы удаляет токен и пользователя из списка онлайн.

### 2. Комната чата

- После входа пользователь попадает в общую комнату.
- Чат представлен как HTML-страница с:
  - формой отправки сообщений;
  - отображением последних сообщений;
  - подключением WebSocket для получения новых сообщений.

### 3. Взаимодействие в реальном времени

- Используется Redis Pub/Sub:
  - сообщения публикуются в Redis;
  - WebSocket-соединения получают сообщения из Redis и отображают их на странице.

### 4. Хранение сообщений (опционально)

- Сообщения записываются в Redis Streams (`XADD stream:chat`).
- Возможность извлекать последние сообщения при загрузке страницы.

### 5. Отображение онлайн-пользователей (опционально)

- Хранение списка активных пользователей в Redis (например, `SADD online_users`).
- Отображение количества или списка онлайн-участников на странице чата.

## Критерии проверки

- Корректность регистрации, входа, выхода.
- Работа чата в реальном времени без перезагрузки страницы.
- Использование Redis для авторизации и доставки сообщений.
- Отсутствие ошибок при запуске и использовании.
- Читаемый и структурированный код.
- Оформление проекта - по желанию, для приемки достаточно минимального фнукционала.
