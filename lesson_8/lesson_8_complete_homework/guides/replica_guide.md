# Репликация в Redis

Эта инструкция поможет настроить простую репликацию между двумя Redis-серверами на одной машине.

## Что мы будем делать

- Запустим два Redis-сервера:  
  мастер — на порту `6379`  
  реплика — на порту `6380`

---

## Шаг 1. Подготовка директорий и конфигурации

Создаём каталоги:

```bash
mkdir -p ~/redis-replica/{6379,6380}
```

Создаём файл `6379.conf` с конфигурацией мастера:

```ini
port 6379
appendonly yes
dir ~/redis-replica/6379
```

Создаём файл `6380.conf` с конфигурацией реплики:

```ini
port 6380
appendonly yes
dir ~/redis-replica/6380
replicaof 127.0.0.1 6379
```

---

## Шаг 2. Запуск Redis-серверов

Запускаем мастер:

```bash
redis-server ~/redis-replica/6379/6379.conf
```

Запускаем реплику:

```bash
redis-server ~/redis-replica/6380/6380.conf
```

---

## Шаг 3. Проверка

Подключаемся к мастеру:

```bash
redis-cli -p 6379
```

Пробуем установить ключ:

```redis
SET mykey "hello"
```

Подключаемся к реплике:

```bash
redis-cli -p 6380
```

Пробуем получить ключ:

```redis
GET mykey
```

Если всё работает, на репике будет тот же ключ.

---

## Шаг 4. Проверка роли

Можно убедиться в роли каждой ноды:

```bash
redis-cli -p 6379 INFO replication
redis-cli -p 6380 INFO replication
```

На мастере будет `role:master`, на реплике — `role:slave`.

---

## Что дальше

При остановке мастера реплика продолжит работать, но новые данные туда писать нельзя.  
Если мастер восстановится — реплика автоматически продолжит синхронизацию .
