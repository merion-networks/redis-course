# Добавление новых нод в Redis Cluster и ребалансировка

---

## Что мы хотим сделать

- Добавить одну или несколько новых Redis-нод к уже работающему кластеру
- Равномерно перераспределить слоты между всеми мастерами (rebalance)

---

## Шаг 1. Подготовка новой ноды

Допустим, у тебя будет новая нода на порту `7006`.

Создай директорию и конфиг:

```bash
mkdir -p configs/7006
cp configs/7000/7000.conf configs/7006/7006.conf
sed -i 's/7000/7006/g' configs/7006/7006.conf
```

Убедись, что в конфиге есть:

```ini
port 7006
cluster-enabled yes
cluster-config-file nodes-7006.conf
dir ./configs/7006
bind 127.0.0.1
protected-mode no
```

Запусти её:

```bash
redis-server configs/7006/7006.conf &
```

---

## Шаг 2. Присоединение новой ноды к кластеру

Используем команду `CLUSTER MEET`, указав любую существующую ноду (например, 7000):

```bash
redis-cli -p 7006 cluster meet 127.0.0.1 7000
```

Проверь, что нода появилась:

```bash
redis-cli -c -p 7000 cluster nodes
```

---

## Шаг 3. Сделать новую ноду мастером (если нужно)

Если ты хочешь, чтобы новая нода участвовала как **мастер** (со слотами), переходи к ребалансу.

Если хочешь сделать её **репликой** — найди ID мастера и выполни:

```bash
redis-cli -p 7006 cluster replicate <ID-мастера>
```

---

## Шаг 4. Ребаланс слотов

Распределим слоты равномерно между всеми мастерами (включая новую ноду):

```bash
redis-cli --cluster rebalance 127.0.0.1:7000
```

По умолчанию утилита сама найдёт все мастеры и перераспределит слоты.

---

## Шаг 5. Проверка

Проверь распределение слотов:

```bash
redis-cli -c -p 7000 cluster nodes
```

Ты увидишь, что часть слотов теперь обслуживает `7006`.

---

## Примечание

Если ты добавляешь сразу несколько новых нод, можно сделать `meet` для каждой и потом **один раз** вызвать `--cluster rebalance`.
