## Домашнее задание: Поиск ключей и очистка кэша в Redis

### Цель:
Научиться использовать команды поиска ключей в Redis (KEYS, SCAN) для итеративного перебора и фильтрации данных, а также реализовать механизм очистки кэша на основе найденных ключей.

### Задачи:
1. Реализация эндпоинта поиска ключей:
   - Создайте административный эндпоинт, который принимает два параметра:
     - `pattern`: шаблон для поиска (например, `post:*`).
     - `method`: способ поиска – либо `keys`, либо `scan`.
   - При выборе метода `keys` используйте команду KEYS, чтобы сразу вернуть все ключи, удовлетворяющие шаблону.
   - При выборе метода `scan` итеративно перебирайте ключи с помощью SCAN, собирайте все найденные ключи и возвращайте их вместе с количеством итераций.
   - В ответе верните список найденных ключей, время выполнения и, для метода SCAN, количество итераций.
   - Обсудите в комментариях преимущества использования SCAN вместо KEYS для большого количества данных.

2. Реализация эндпоинта очистки кэша:
   - Создайте эндпоинт, который ищет все кэшированные ключи, соответствующие шаблону `post:*`.
   - Если общее количество найденных ключей превышает заданное значение (например, 10), оставьте только первые 10 (например, отсортировав ключи лексикографически или по другому критерию) и удалите остальные.
   - В ответе верните информацию о количестве удалённых ключей и общем числе ключей до очистки.

3. Рекомендации по реализации:
   - Используйте асинхронные вызовы Redis для выполнения команд KEYS, SCAN, и удаления ключей.
   - Напишите вспомогательную функцию (например, `get_all_keys`), которая итеративно собирает все ключи, удовлетворяющие шаблону, используя SCAN.
   - Протестируйте эндпоинты через Swagger UI или Postman, убедитесь, что результаты корректны и возвращают ожидаемые данные.
   - Добавьте комментарии в коде с пояснением, почему метод SCAN предпочтительнее для продакшена при большом объёме ключей.

### Итог:
В результате выполнения домашнего задания ваше приложение получит два новых административных эндпоинта:
- Один для поиска ключей в Redis с возможностью выбора метода поиска.
- Другой для очистки кэша постов при превышении заданного лимита.
